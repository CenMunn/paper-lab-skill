# 面向简单作业的论文与实验报告的 Skill

面向课程小论文、基础综述和简单实验报告，按照用户的材料与目标格式生成、修改或检查文档；已有学位论文、期刊模板时也可据其辅助整理。默认交付可编辑 Word（.docx），默认 A4 纵向排版。格式默认值来自用户的个人偏好，不代表所有学校、课程、专业或期刊的统一规范。

## 开始任务

先判断用户需要课程论文、实验报告、某个章节、润色、排版还是检查。只处理本次要求的范围；仅请求文字或意见时，不强制生成完整文件。

从当前对话和用户提供的文件提取：主题或研究问题、论文类型、语言、字数、学校或期刊模板、已有正文、数据、文献及交付要求。已提供的信息不再询问。

实验报告任务还要提取课程要求、实验指导书、实际操作记录、原始数据和思考题；先读取 [简单实验报告规则](references/lab-reports.md)。

- 缺少主题等会决定内容的关键信息时，提出少量具体问题；同时处理不依赖答案的工作。
- 其余信息采用本文默认值，简短说明假设，不把每项默认值都变成审批问题。
- **生成论文或实验报告文件时，默认输出 Word，并在用户尚未明确选择时询问一次：“默认生成可编辑 Word 文档，是否还需要 LaTeX 源码？”** 有异步提问工具时使用工具，继续制作 Word。未答复时仅交付 Word，不等待、不自动生成 LaTeX。
- 用户已明确需要或不需要 LaTeX 时直接执行，不重复询问。用户明确指定其他交付格式时遵循该要求。

## 先确定有效格式

应用顺序：用户本次明确要求 → 用户指定的学校、期刊或课程模板 → 本 skill 的论文类型配置 → 通用默认值。同一层级冲突时，优先更具体且更新的要求；无法判断且会影响提交时，提出针对性问题。

如果用户要求与指定模板不同，遵循用户要求并简短指出偏离项，不能同时声称完全符合模板。保留模板已经定义的样式、栏目和结构，按字段补齐缺失项，不用默认值覆盖整份模板。

写作前读取 [格式参数表](references/formatting.md)，确定本次样式：页面、论文类型、语言、标题、正文、图表、文献、页码。生成过程中使用同一份有效配置，避免各章节各自选值。

**没有明确的方向要求时，所有页面和分节均为纵向。** 横向页面须有用户的明确要求或其指定模板的明确规定。宽表、宽图、长公式本身不构成自动切换横向的依据。优先换行、拆分、调整列宽或移入仍为纵向的附录；双栏与纵向是独立设置。

## 写作与材料边界

根据论文类型组织内容，不把所有论文强制套入同一套章节：

| 类型 | 合适的内容组织 |
| --- | --- |
| 课程小论文、基础综述 | 围绕问题组织引言、主题论述、分析与结论，按作业要求加入摘要与参考文献 |
| 简单实验报告 | 实验目的、原理、仪器材料、实际步骤、数据与处理、误差分析、结论及按需回答思考题；详见实验报告规则 |
| 本科、硕士、博士论文 | 按模板组织摘要、目录、绪论、相关工作、核心研究章节、结论及参考文献；声明、致谢、附录按需加入 |
| 实证或实验研究论文 | 研究问题、相关工作、方法、结果、讨论和结论；方法与实际数据相匹配 |
| 综述、理论、人文社科论文 | 按问题、主题、论点或理论展开；不虚设实验和结果章节 |
| 期刊稿 | 遵循目标期刊结构、篇幅和引用要求；没有模板时标明为通用初稿 |

先形成论证骨架，再撰写段落并检查各节衔接。材料足够时直接完成请求，不设置强制的“先批准提纲才能写正文”环节。摘要、正文结果和结论必须相互对应；不在摘要或结论中引入正文未支持的新发现。

事实性主张要有材料或可核实来源支持。真实研究数据、作者信息、样本量、实验步骤、统计结果和文献条目不能凭空补全。缺失信息以清楚的“待补：具体材料”标记，并列入交付说明；可完成的正文继续写。

- 有原始数据时，保留数据来源、处理方法和计算过程，核对单位、样本量和数值一致性。
- 没有实证数据时，可交付研究方案、方法草稿及结果表格骨架，明确其为初稿；不能把预期结果写成已证实结论。
- 用户明确请求模拟或教学示例时，标注模拟数据和示例结论，保持与真实研究材料的区别。
- 参考文献使用用户提供且能核实的资料，或实际检索核实的来源。核对作者、题名、年份、期刊和 DOI 等元数据，引用内容与来源相符。未核实项标明待核实，不编造条目凑数。
- 没有指定引文格式时，暂用全文一致的顺序编码制 [1]；指定标准或期刊体例时按其要求处理，涉及标准版本时核实适用版本，不凭记忆宣称为最新标准。

### 正文说明与注释取舍

默认保持正文和图表简洁，不为每幅图、每张表机械添加“注”。正文、表头或题注已经清楚说明的内容，不在相邻注释中重复；“保留原始文件不变”“已逐项核对”等制作或核验过程通常留在工作记录中。

保留会影响理解和判断的来源、单位、统计范围、指标口径、关键限制，以及模板要求的说明。选择最合适的位置说明，避免同一限定在正文、表注和图注反复出现；必要的来源引用及真实性说明不能为了精简而删除。用户提供修改稿时，以实际删改判断其偏好，不把“删掉重复注释”扩大为“删除所有注释”。

## 生成文件

### 默认 Word

输出真正可编辑的 .docx。使用命名样式、标题级别、自动编号、题注和交叉引用；正文不使用空格缩进，不用空段落推页，不手打页码。中西文字体分别设置，不能只设置西文字体后假定中文也已应用。

生成或修复 Word 前，读取 [Word 字体与三线表实现](references/word-formatting.md)。没有模板自定义映射时，将一级至三级标题实际绑定到 Word 的 Heading 1–3（中文界面“标题 1–3”），在样式中明确设置中文字体；清理会覆盖字体和字号的直接格式，并核对序列化后的实际文件。不能仅凭应用了标题样式、文字已加粗或 `font.name` 的返回值判定中文字体正确。

**默认将文档题目、一级标题和二级标题设为加粗。** 在 Title、Heading 1、Heading 2 或对应模板样式中设置，中文标题同时保留黑体字体；“黑体”和“加粗”是两个独立属性。中文三级标题默认保持常规字重，英文稿及模板例外按格式参数表执行。检查直接格式、字符样式和编号是否覆盖标题字重，不能只对个别标题手动加粗。

正文也要单独初始化并绑定统一的正文样式。默认中文正文为宋体小四号，明确数值为 **12 pt**；四号为 14 pt，不得混淆。按有效配置设置 Normal（中文界面通常为“正文”）及实际使用的正文派生样式，逐段清理正文中的直接字号覆盖；不能只改 Normal 后放任 Body Text 等样式保留 14 pt。选定博士配置、学校模板或用户明确指定其他字号时，采用相应有效值。交付前核对正文的实际生效字号，不能仅检查样式定义。

**正常阅读时隐藏编辑标记，保留标题分页控制。** 标题左侧的小黑方块若来自“显示编辑标记”模式及“与下段同页”等分页属性，按非打印标记处理，保留标题样式、大纲级别、自动编号及必要分页属性。交付前检查正常阅读视图和打印预览中没有该标记；具备 Word 自动化能力时，可关闭本次目标文档窗口的编辑标记显示。不自动修改全局模板、注册表或其他文档的显示偏好。

按 [标题方形编辑标记与跨机器显示](references/word-formatting.md#标题方形编辑标记与跨机器显示) 区分非打印标记、真实方块字符和项目符号。收件人电脑开启编辑标记后仍可能看到分页标记，不能承诺仅靠 DOCX 内容强制隐藏所有电脑的编辑标记；需要时说明“开始 → ¶ 显示/隐藏”及显示选项的处理方法。

图表保持清晰；表格可编辑；公式使用 Word 公式或其他可编辑的数学结构。目录使用标题层级生成。分别设置前置部分与正文的分节、页码格式和起始值，检查页眉页脚链接关系。

未指定表格形式时，学术数据表默认使用三线表；具体规则见格式参数表。本文确定的学术版式优先于辅助文档技能的通用外观预设，包括网格边框、彩色表头、隔行底色和默认标题字体。辅助技能继续负责文件创建和渲染，不得在创建最后阶段把已确定的学术样式改回通用预设。

环境提供 documents 文档技能时，按该技能执行具体 DOCX 创建与渲染流程；本 skill 决定论文或实验报告内容和有效格式。缺少字体或渲染能力时说明具体限制，不把结构检查等同于视觉检查。

### 用户需要 LaTeX 源码时

Word 保持默认交付，同时提供与其内容、引文、图表编号和格式配置一致的独立 LaTeX 工程；用户明确只要 LaTeX 时仅提供所需文件。

工程包含主文件、实际引用的图片、参考文献数据及必要的样式文件，使用相对路径。中文稿采用支持中文的编译方案，注明编译引擎和字体依赖；不能把 Word 全页截图嵌入 LaTeX 充当源码。现有工程按其结构编辑，不重建不相关文件。

在 Codex 中新建本地 LaTeX 工程时，使用可用的 create_latex_project、open_in_codex 和 compile_latex_document 工具创建、展示和检查；其他环境使用可用的等效工作流。只有实际编译成功才报告“编译通过”。默认不追加 PDF 交付；PDF 按用户要求提供。

## 检查与交付

交付前读取并执行 [交付检查表](references/delivery-checklist.md)。按本次有效配置检查实际文件；修改影响分页后重新检查相应页面。发现问题先修复，再交付。

最终回复提供：文件链接、采用的格式配置、实际完成的检查，以及仍需用户补充或确认的少量具体事项。存在占位符、未核实引用、未更新目录或未完成渲染时，明确标为初稿或列出限制，不称为可直接提交的最终稿。

## 调用示例

“使用 $paper-writing，根据附件资料撰写中文硕士论文初稿，采用默认硕士格式，先交付 Word。”

执行时：应用硕士配置，询问一次是否需要 LaTeX 源码并继续制作 Word；数据缺口明确标注，正文和附录均使用纵向页面，交付前检查页码、样式和实际渲染效果。

“使用 $paper-writing，根据实验指导书和附件实测数据整理一份课程实验报告。正文宋体小四，数据用三线表，输出 Word。”

执行时：按实验报告规则组织内容，保留原始记录并核对数据处理；没有课程模板时采用通用格式，正文宋体 12 pt、A4 纵向，不自动加入学位论文的封面声明或罗马数字前置页。

# 论文格式参数表

这些参数记录用户的默认偏好。学校、专业、期刊及用户本次明确要求优先；不将此表称为通用强制标准。

## 1. 页面与分节

| 项目 | 默认值 |
| --- | --- |
| 纸张 | A4，宽 210 mm × 高 297 mm |
| 页面方向 | 纵向，应用于所有分节，包括封面、目录、正文和附录 |
| 页边距 | 上 2.5 cm、下 2.5 cm、左 3 cm、右 2 cm |
| 页眉位置 | 距纸张上边缘 1.5 cm |
| 页脚位置 | 距纸张下边缘 1.75 cm |
| 正文对齐 | 两端对齐 |
| 栏数 | 单栏；期刊或用户指定双栏时覆盖 |
| 正文首行缩进 | 2 个字符，使用段落格式设置 |

不要把页眉页脚距纸张边缘的位置当作正文上下边距。默认无额外装订线；模板有装订线、镜像页边距等要求时按模板设置。不自行填入学校名、作者名或其他未知页眉内容。

纵向与双栏并不冲突。无方向要求的旧文件若含横向节，应改为纵向并重新组织内容；若横向来自用户明确指定的模板，则保留对应要求。其他节不因此自动转为横向。

## 2. 论文类型配置

先选类型，再按语言应用下一节的字体。下表字体和字号针对中文正文；英文整篇论文使用英文样式表，中文论文中的英文、数字沿用所在样式的字号。

| 类型 | 中文正文 | 正文行距 | 正文段前 / 段后 |
| --- | --- | --- | --- |
| 通用论文、未指定类型 | 宋体，小四，12 pt | 1.5 倍 | 0 / 0 |
| 课程小论文、简单实验报告 | 宋体，小四，12 pt | 1.5 倍 | 0 / 0 |
| 本科毕业论文 | 宋体，小四，12 pt | 1.5 倍 | 0.5 行 / 0.5 行 |
| 硕士学位论文 | 宋体，小四，12 pt | 固定值 20 pt | 0 / 0 |
| 博士学位论文 | 宋体，五号，10.5 pt | 1.25 倍 | 0 / 0 |
| 期刊论文，无目标模板 | 中文宋体、英文 Times New Roman，12 pt | 暂用 1.5 倍 | 0 / 0 |

“通用正文小四”不能覆盖已选定的博士正文五号。博士三级标题仍是黑体小四。用户只修改某一参数时，保留类型配置中的其余参数。

字号换算：小四号 = 12 pt，四号 = 14 pt，五号 = 10.5 pt。默认正文实际应为宋体 12 pt；14 pt 是本表中文二级标题的字号，不能混用。OOXML 中字号使用半磅单位，12 pt 对应 `w:sz="24"`，14 pt 对应 `w:sz="28"`；`w:szCs` 也应与有效字号一致，避免保留模板中的另一套字号。

通用稿、硕士、博士的零段间距，以及无期刊模板时的行距，是为消除歧义补充的工作默认值。期刊稿缺少目标要求时注明“通用初稿，尚未核对投稿格式”。

行距区分“多倍”与“固定值”：1.25 倍不是固定 15 pt，固定 20 pt 不是 20 倍。硕士正文默认固定 20 pt；展示公式等特殊段落若发生裁切，可单独设置足够行高，并保留普通正文行距。

## 3. 中文样式

| 内容 | 字体与字号 | 对齐与段落 |
| --- | --- | --- |
| 论文题目 | 黑体，加粗，二号，22 pt | 居中；段前、段后各 1 行；无首行缩进 |
| 一级标题 | 黑体，加粗，三号，16 pt | 默认左对齐；段前、段后各 0.5 行；无首行缩进 |
| 二级标题 | 黑体，加粗，四号，14 pt | 默认左对齐；段前、段后各 0.5 行；无首行缩进 |
| 三级标题 | 黑体，常规字重，小四，12 pt | 默认左对齐；段前、段后各 0.5 行；无首行缩进 |
| 正文 | 宋体；字号见类型配置 | 两端对齐；首行缩进 2 字符；行距与段间距见类型配置 |
| 摘要正文、关键词内容 | 宋体，小四，12 pt | 摘要按正文段落排版；关键词行无首行缩进 |
| “摘要”“关键词”标签 | 黑体，小四，12 pt | 关键词标签与内容同段；摘要标签独立成行 |
| 参考文献条目 | 宋体，五号，10.5 pt | 悬挂缩进 2 字符；无正文式首行正缩进 |
| 注释（确有需要时） | 宋体，小五，9 pt | 正文补充采用脚注并与标记对应；图表必要说明随图表放置 |
| 图题、表题 | 宋体，五号，10.5 pt | 图题在图下、表题在表上；无首行缩进 |

除表中另有说明，行距沿用类型配置；标题采用与下段同页，避免标题孤立在页尾。参考文献、图表题和脚注不继承本科正文的 0.5 行段间距，默认段前段后为 0。脚注默认单倍行距。

正常阅读时隐藏编辑标记，保留以上标题分页控制。在 Word 开启“显示编辑标记”时，“与下段同页”“段中不分页”“段前分页”等属性可能由标题左侧的小黑方块提示，该标记不属于标题正文。检查时保留必要分页属性，确认关闭编辑标记后的阅读视图及打印预览中无该标记；具体区分方法见 [Word 实现说明](word-formatting.md#标题方形编辑标记与跨机器显示)。

标题字重与字体分别设置：题目、一级和二级标题默认是“黑体且加粗”，不是二选一；中文三级标题不因本次偏好扩展为全部加粗。用户或模板另有规定时，以其有效配置为准。

中文论文中的西文和数字使用 Times New Roman，字号与所在正文、标题、题注或文献样式一致。数学内容保留数学字体和必要的斜体、上下标，不将所有符号强制替换为正文字体。

“首行缩进 2 字符”随字号变化：12 pt 正文约 24 pt，10.5 pt 正文约 21 pt；优先使用字符缩进属性。10.5 pt 参考文献悬挂 2 字符约 21 pt，左缩进与首行负缩进配合，不能写成首行正缩进。段前段后“0.5 行”使用行单位；若库仅支持点单位，按实际样式行高换算并核对效果，不把 0.5 行写成 0.5 pt。

## 4. 英文样式

| 内容 | 字体与字号 | 默认设置 |
| --- | --- | --- |
| Title | Times New Roman，16 pt | 加粗、居中；段前段后各 1 行 |
| 一级 / 二级 / 三级标题 | Times New Roman，14 / 13 / 12 pt | 加粗、左对齐；段前段后各 0.5 行 |
| Body Text | Times New Roman，12 pt | 两端对齐；行距按论文类型 |
| Abstract & Keywords | Times New Roman，11 pt | 标签加粗 |
| References | Times New Roman，10.5 pt | 悬挂缩进；具体引文格式优先 |
| Figure / Table captions | Times New Roman，10.5 pt | 图下、表上 |

英文标题层级 14 / 13 / 12 pt 与参考文献 10.5 pt，是用户给定范围内的明确默认选择。模板指定其他值时覆盖。整篇英文稿默认正文首行缩进 0.5 in、参考文献悬挂缩进 0.5 in；这是补充默认值，不能反向应用到中文稿的“2 字符”。

## 5. 页码、目录与编号

- 学位论文的封面默认不显示页码；摘要、目录等前置部分从小写罗马数字 i 起单独编号，正文从阿拉伯数字 1 重新开始。
- 页码置于页脚居中，使用动态页码字段。前置部分与正文分别设置页码格式、起始值及页眉页脚继承关系，避免重启页码失效。
- 期刊稿、短论文没有独立前置页面时，不强制添加目录和罗马数字分节；从正文开始编页，模板另有要求时服从模板。
- 目录从标题样式生成；更新目录及交叉引用后核对页码。未实际更新字段时明确指出，不手填“看起来正确”的页数。
- 默认标题编号采用 1、1.1、1.1.1；模板采用“第 1 章”等方案时统一使用模板方案。
- 同一稿的图、表、公式各自统一编号；采用全文连续或按章编号时保持一致，并与正文引用对应。

## 6. 图表、公式与可读性

图题在图下，表题在表上。标题简洁，注明必要单位、缩写含义和来源。表格保持可编辑，跨页时重复表头；续表保留可识别的表号。

图表注释按必要性添加。单位、范围和来源已在表头、题注或紧邻正文中交代清楚时，不再重复列注；模板要求或独立阅读时不可缺少的说明应保留。具体取舍遵循 SKILL.md 的“正文说明与注释取舍”。

**没有学校、期刊或用户指定形式时，学术数据表默认使用三线表。** 这是用户工作流的默认选择，不代表所有专业或实验报告都强制使用三线表。记录表、签字表、复杂矩阵或模板明确要求全框线时，按其实际用途或明确要求设置。

普通三线表保留顶线、完整表头下方的栏目线、底线，不画竖线和数据行之间的横线。默认顶线与底线为黑色 1.5 pt，栏目线为黑色 0.75 pt；白底、黑字，不加彩色表头和隔行底色。复合表头的栏目线放在最后一个表头行下方，必要的局部辅助线按数据分组设置；跨页续表按模板及清晰识别的需要处理，不机械地把每个物理页面限制为三条线。

不能只把表格样式命名为“三线表”或删除一层边框就视为完成：检查表格样式、表级和单元格级边框是否还有遗留竖线/网格，核对实际渲染。具体实现参见 [Word 字体与三线表实现](word-formatting.md)。

宽表在默认页面正文宽度 160 mm 内，通过合理列宽、单元格换行、分组拆表或纵向附录处理。必要时精简重复文本，但不删除关键数据；不通过极小字号牺牲可读性。宽图可拆分子图，长公式可分行。上述处理均不能自行引入横向页面。

展示公式居中，编号右对齐。使用公式对象、制表位或合适的公式布局结构对齐，避免空格拼接。核对上下标、希腊字母、正负号、向量、单位和公式编号。

## 7. 常见误用

| 误用 | 正确处理 |
| --- | --- |
| 使用软件自带的四边 2.54 cm | 按有效配置逐边设置；默认是上/下 2.5、左 3、右 2 cm |
| 为宽表自动插入横向节 | 保持纵向并重组表格；明确要求横向时才改 |
| 把博士正文设为通用 12 pt、1.5 倍 | 应用博士 10.5 pt、1.25 倍配置 |
| 只改 Normal 样式便认为全文一致 | 检查继承、直接格式、表格、文本框、脚注和各节 |
| `font.name = '黑体'` 后就认定中文字体正确 | 显式设置 East Asian 字体并检查最终文件及可用字体 |
| 把加粗当成黑体字体 | 中文字体选择“黑体”（SimHei），加粗属性按有效配置另设 |
| 标题设为黑体后忽略加粗 | 默认在 Title、Heading 1、Heading 2 样式中明确加粗，并检查运行级覆盖 |
| 每张图表都附一段重复表注或制作说明 | 按必要性保留来源、口径与关键限制，删去已在正文交代的重复说明 |
| 直接套用通用文档技能的网格表和底色 | 学术数据表按三线表默认值设置；明确模板要求优先 |
| 用空格缩进、手打页码 | 使用段落属性、分节及页码字段 |
| 把 Markdown 字号说明当作已排版 Word | 生成并检查实际 DOCX 文件 |

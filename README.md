# 面向简单作业的论文与实验报告的 Skill

**把时间花在内容和分析上，少为 Word 格式反复返工。**

这是一个给支持 Skills 的 AI 助手使用的中文规则包，面向课程小论文、基础综述和简单实验报告。提供作业要求、主题和已有材料后，它会指导 AI 整理内容、统一排版，并默认交付可继续修改的 **Word 文档**。

如果你经常遇到“标题看起来像标题，却无法统一修改”“小四号变成四号”“三线表变成网格表”，这个 Skill 就是为减少这些重复工作而做的。

**默认 Word · A4 纵向 · 宋体小四 · 统一标题样式 · 学术三线表 · 按需 LaTeX**

[快速使用](#快速使用) · [安装方法](#安装方法) · [默认格式](#默认格式) · [标题前的小黑方块](#标题前的小黑方块) · [持续更新](#持续更新)

## 它能帮你做什么

| 任务 | 可以提供的帮助 |
| --- | --- |
| 课程小论文 | 根据主题、字数和材料组织提纲、撰写初稿、修改章节及整理格式 |
| 基础综述 | 围绕问题梳理材料与论点，整理引文和参考文献，标明待核实来源 |
| 简单实验报告 | 按实验目的、原理、步骤、原始数据、数据处理、误差分析和结论组织内容，按需回答思考题 |
| 已有文档整理 | 在保留内容和真实数据的基础上，统一标题、正文、题注、页码与表格样式 |
| Word 样式管理 | 将标题和正文绑定到相应样式，方便后续通过修改样式统一调整格式 |
| 补充 LaTeX 源码 | 默认先制作 Word，询问是否需要 LaTeX；明确需要时再提供对应工程 |

有学校或教师模板时，优先按模板执行；已有学位论文和期刊要求时也可据其辅助整理。本项目主要服务简单作业，具体提交规范仍需按课程、学校或期刊要求核对。

## 方便在哪里

- **少重复描述要求。** 字体、字号、页边距、标题层级和图表规则集中在 Skill 中，每次提供本次作业的差异即可。
- **后续修改更方便。** 一级标题统一使用标题样式；修改一次样式，就能同步调整所有绑定的同级标题。正文也有独立的样式和字号检查。
- **更容易发现常见格式问题。** 明确区分黑体与加粗、小四号与四号、中西文字体槽位，并检查直接格式有没有覆盖样式。
- **表格与页面更统一。** 学术数据表默认采用三线表，宽表优先换行或合理拆分；没有明确要求时，全篇保持 A4 纵向。
- **论文和报告分别组织。** 课程实验报告不会自动套上学位论文的声明、致谢和罗马数字前置页。
- **缺什么说清楚。** 缺少实验记录、原始数据或可靠来源时，列出待补项，方便继续完善。

## 快速使用

安装后，在支持 Skills 的 AI 助手中调用 `$paper-writing`，并提供作业要求和材料。例如：

### 写一篇课程小论文

```text
使用 $paper-writing，帮我整理一篇关于校园节能设计的课程小论文，
约 3000 字。附件是课程要求和参考材料。
默认生成 Word，正文宋体小四，标题使用统一样式。
```

### 整理一份实验报告

```text
使用 $paper-writing，根据附件中的实验指导书和实测数据，
整理一份课程实验报告。
展示必要的数据处理过程，分析误差，回答指导书中的思考题。
输出 Word，数据表用三线表，没有特殊要求的页面保持纵向。
```

### 修改已有 Word 的格式

```text
使用 $paper-writing，检查并整理这份 Word 的格式。
正文统一为宋体小四号 12 pt；一级、二级标题为黑体加粗，
分别使用对应标题样式；学术数据表采用三线表。
保留原文内容和实测数据，列出仍需我补充的信息。
```

建议一起提供：**题目、课程要求、目标字数、学校或教师模板、已有正文、原始数据、参考材料**。已有的信息无需重复解释；要求越清楚，整理后的文档越接近你的实际需要。

## 安装方法

### 下载文件夹

1. 在本仓库选择 **Code → Download ZIP**，或克隆仓库。
2. 解压后找到 [`paper-writing`](paper-writing/) 文件夹，保持内部目录完整。
3. 将整个 `paper-writing` 文件夹放到所用 AI 工具支持的 Skills 目录。
4. 在工具识别该 Skill 后打开会话，使用 `$paper-writing` 调用。

本项目在 Codex 的个人 Skills 目录中使用；该环境可使用 `~/.codex/skills/paper-writing/`。其他工具请使用其支持的目录。已有同名目录时，先备份自己的修改，再替换或合并更新。

也可以先克隆仓库：

```bash
git clone https://github.com/CenMunn/-skill.git coursework-skill
```

然后安装其中的 `coursework-skill/paper-writing`，仓库根目录的 README 不需要放进 Skill 目录。

### 运行环境

Skill 会指导 AI 选择合适的文档工具；实际生成可编辑 Word 需要 AI 环境具备创建、读取和检查文档的能力。只支持文本对话的环境，可以使用规则整理内容，但未必能直接导出 `.docx`。

如果 AI 使用仓库内的 Python 格式辅助函数，需要 `python-docx`；仓库的 `requirements.txt` 记录了辅助函数已使用的版本。已有环境提供该依赖时可直接使用，按需安装：

```bash
python -m pip install -r requirements.txt
```

Word 字体显示还取决于电脑是否具备对应字体。默认中文使用宋体和黑体；缺少这些字体时，需要选择可用的处理方案并说明差异。LaTeX 源码及编译检查则依赖所用环境的 LaTeX 工具。

## 默认格式

下表为通用课程小论文和简单实验报告的默认值。**用户明确要求及学校、教师、期刊模板优先。**

| 项目 | 默认设置 |
| --- | --- |
| 交付文件 | 可编辑 Word `.docx`；询问是否需要 LaTeX 源码 |
| 页面 | A4，纵向；附录也保持纵向，除非有明确要求 |
| 页边距 | 上、下各 2.5 cm；左 3 cm；右 2 cm |
| 正文 | 宋体，小四号 **12 pt**；西文和数字按配置使用 Times New Roman |
| 通用正文段落 | 1.5 倍行距，首行缩进 2 字符，段前段后 0 |
| 文档题目 | 黑体，加粗，二号 22 pt，居中 |
| 一级标题 | 黑体，加粗，三号 16 pt |
| 二级标题 | 黑体，加粗，四号 14 pt |
| 中文三级标题 | 黑体，常规字重，小四号 12 pt |
| 学术数据表 | 默认三线表，白底黑字；表题在表上，图题在图下 |

**小四号是 12 pt，四号是 14 pt。黑体是字体，加粗是独立属性。**

仓库还保留了本科、硕士、博士及英文稿件的格式配置，详见 [格式参数表](paper-writing/references/formatting.md)。这些是可覆盖的默认值，不代表所有院校的统一标准。

## 标题前的小黑方块

如果在标题左侧看到一个小黑方块，它**可能是 Word 的非打印编辑标记**，提示该段落设置了“与下段同页”“段中不分页”等分页属性。这些属性有助于避免标题孤立在页尾。

正常阅读时，可通过 **开始 → ¶ 显示/隐藏** 关闭编辑标记。Windows Word 通常也可以使用 **Ctrl + Shift + 8** 切换。

如果关闭 ¶ 后仍显示，可检查 **文件 → 选项 → 显示** 中“始终在屏幕上显示这些格式标记”和“显示所有格式标记”的设置。操作说明可参考 [Microsoft 官方帮助](https://support.microsoft.com/en-us/word/show-or-hide-tab-marks-in-word)。

- 如果它只在编辑标记模式下出现、打印预览中不出现，保留标题的分页控制，正常阅读时隐藏标记即可。
- 如果打印预览中仍有方块，需要继续检查是否误加了真实方块字符、项目符号或错误的编号格式。

**本项目的默认选择是“正常阅读时隐藏编辑标记，保留标题分页控制”。** 不同电脑的 Word 显示偏好可能不同，DOCX 不能强制所有收件人的编辑标记开关一致；不要为了消除非打印提示而把标题样式和分页设置全部清掉。

## 使用时了解这些边界

- 根据已有材料写作和整理；没有真实实验数据时提供待补草稿，不编造测量值或实验结论。
- 参考文献应能核实，未核实的来源会标明，不通过虚构作者、题名或 DOI 凑数量。
- Word 样式、实际字体、分页和三线表仍需检查。不同系统、字体和文档工具可能影响呈现；没有完成渲染或编译时应说明验证范围。
- 最终核对课程要求、数值与结论，再决定是否提交。它能帮助减少重复工作，实际内容仍需要你理解和确认。
